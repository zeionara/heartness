# Translation style sheet

Give this sheet to every translating agent — each agent sees only its own
chunk of the file.

## Register
- Write what a person would actually say in Russian, not a literal rendering of
  the English word order.
- Keep the force of the source. A crude comedy stays crude: profanity,
  mockery, drunken rambling, sexual talk. Softening it changes the film.
- Keep the voice of the character: a stutterer stutters, a drunk slurs, a
  bureaucrat is formal, a teenager is not a professor.
- Keep broken speech broken. `Salum... mineh...` stays a garbled incantation
  (`Салум... майнэ...`), not a tidied-up phrase.
- Do not summarize, expand or explain. Subtitle text is speech, not narration.
- Keep the meaning of jokes intact — often by keeping the wordplay in Russian
  rather than translating the setup literally.

## Names and titles
- Transliterate consistently and keep one spelling for the whole file:
  George → Джордж, Daisy → Дейзи, Sam → Сэм, Vanessa → Ванесса, Chris → Крис,
  Maya → Майя, Wes → Уэс, Blothar → Блотар, Hemlock → Хемлок, Riptide → Риптайд,
  Skeeto → Скито, Botulism → Ботулизм, Geppetto → Джеппетто, Frugal Boots →
  Фругал Бутс, Grodius Maximus → Гродиус Максимус.
- Show and band names: keep what is written in Latin when it is a brand or a
  stage name (GWAR, YTS.BZ, YIFY); translate titles of works and give them
  guillemets: "The Curious Chorus" → «Любопытный хор», "How It's Made" →
  «Как это устроено».
- If several subtitle files of the same film are translated, the wording of a
  repeated line must be identical in all of them.

## Markup that must survive
- `- ` dialogue dashes: keep them, including two dashes for two speakers.
- Speaker tags (`- Sam: Hey.` → `- Сэм: Эй.`): transliterate the name, keep the
  tag shape.
- `♪` music notes: keep them at the same line starts and ends; translate the
  lyrics between them. A repeated song keeps identical wording every time.
- `[...]` sound and action descriptions: translate inside the brackets, keep
  the brackets: `[Eerie music plays]` → `[зловещая музыка]`, `[Sam screams]` →
  `[Сэм кричит]`, `[Beep]` → `[пиканье]`, `[Static]` → `[шум помех]`.
- Lines that are only punctuation, `-` or `♪` stay as they are.
- Quoted spoken words inside a cue stay quoted: `«Dance, Dance, Dance»`.

## Line layout
- 1–2 text lines per cue, each ≤ 45 characters. Russian runs ~10–15% longer
  than English; if a cue no longer fits in two lines, rebalance the wording
  instead of adding a third line.
- Keep the source's line split when it still works. It is the difference
  between a subtitle that reads well and one that scrolls.
- Keep a cue's text on the same lines as the source wherever the length allows.

## Small vocabulary of reactions
`Aaah!` → А-а-а!, `Whoa.` → Ого., `Hmm.` → Хм., `Ha ha ha!` → Ха-ха-ха!,
`Yay!` → Ура!, `Ouch!` → Ауч!, `Hey!` → Эй!, `Come on!` → Давай!,
`What the fuck?!` → Какого хуя?!, `Shit!` → Блядь!, `Don't worry.` →
Не переживай.
